# Rahina Nawab Ali — Portfolio (Next.js + Tailwind CSS)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```

- `app/portfolio.css` — original portfolio styles (unchanged)
- `app/globals.css` — Tailwind CSS (theme + utilities; preflight off so the design stays identical)
- `components/` — one component per section
- Deploy: push to GitHub and import in Vercel (Framework: Next.js, no extra settings)
